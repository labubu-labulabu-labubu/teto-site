FAQ

几个常被问的

没有正版账号能玩吗？

可以，用离线模式，随便起个名字。想上正版服务器再登录微软账号就行。

要自己装 Java 吗？

不用。启动器会按你选的游戏版本去准备对应版本的 Java，省得你为了一个 1.7.10 的整合包去装 Java 8。

它会不会乱装东西？

不会。所有模组都下在你自己指定的游戏目录里，删掉就干净了。它不碰系统目录。

支持哪些加载器？

原版、Fabric、Forge、NeoForge、Quilt。整合包（.mrpack / .zip）也能直接导入。
