怎么用

  1. 下载上面的安装版，双击装。会问装在哪、要不要桌面图标，装完开始菜单里就有了。不想装就用便携版，双击直接开。
  2. 第一次开会让你选游戏目录；默认用桌面上的 .minecraft，想换就点「浏览」。
  3. 左边选版本，没装的先点「安装 / 更新」；然后点「启动游戏」。

第一次运行 Windows 可能会弹「已保护你的电脑」。文件有数字签名，但用的是自签名证书，没有买商业代码签名证书，所以系统默认不信任它。点「更多信息 → 仍要运行」就行；不放心可以先核对上面的 SHA-256。

能做什么

  • 选版本、下载游戏文件、启动，全程在界面里点，不用手动改配置文件。
  • 以前装好的版本能直接导入：选一下目录就把版本搬进来，不用重下。

  • 工具中心：诊断、模组管理、存档备份还原、截图、磁盘占用。
  • 离线模式：没有正版账号也能玩单人和离线服务器，要连正版服务器再登录微软账号。
  • 也可以在输入框里直接写「装个钠和 Iris」，它按你的游戏版本去找（内置云端 AI，装上就能用，不用另外配置）。

常见问题

要自己装 Java 吗？

不用。启动器会按你选的游戏版本准备对应的 Java 运行时，只准备游戏要用的那个。

它会不会往系统里乱装东西？

不会。安装版只在当前用户下写一条卸载记录（就是让「设置 → 应用」里能卸载用的），不建服务、不动系统目录；便携版连这条都不写。配置和日志放在 %LOCALAPPDATA%\DolphinCraftLauncher，游戏和模组都放在你自己指定的目录里。

怎么卸载？

装过的话，去「设置 → 应用 → 已安装的应用」，找到海豚启动器点卸载；开始菜单里右键也有卸载。只删程序本身、快捷方式和那条卸载记录，.minecraft 里的存档、模组、游戏本体一个都不碰。便携版没有安装过程，把那个 exe 删掉就行。

支持哪些版本？

1.7.10 及以上，原版和主流的模组加载器都可以。

安卓版和电脑版是同一个程序吗？

不是。电脑版是原生的 Windows 程序，一个 exe；安卓版是把启动和模组那一套逻辑搬到手机上，自带 Java 运行时，界面按手机屏幕重排过。两边各自独立安装，账号和存档不互通。

为什么还会提示不安全？

签了，但用的是自签名证书，不是花钱买的商业证书，所以 Windows 默认不信任这个签名者，SmartScreen 照样会提示。核对上面的 SHA-256 能确认文件没被改过。
