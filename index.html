2.3.5 的改动：① 装模组时把必备前置（Fabric API、Architectury 这类）一起装上，装完写明「顺带装了 N 个前置」；已经装好的版本也能补——管理窗口点「检查前置」，缺哪些列出来，点「一键补齐」就装上；② 壁纸能换了，静态图铺满整个窗口，gif / 动态 webp 会动，面板颜色从壁纸里采样再压暗，保证字看得清；③ 内置陶瓦联机，填个名字建房、房间号进房，不用虚拟局域网也不用开端口映射；④ 首页按钮缩成最上面一行，版本列表搬到「游戏」页并分类（正式版 / 快照版 / 愚人节版 / 远古版 / 自建）。
2.3.4 的改动：① 玩家名现在真的是进游戏用的那个名字——以前读账号配置认错字段，名字存进去了、启动时又换回 Player，UUID 也跟着错，改多少次都不生效；② 无边框窗口有任务栏按钮了，最小化后能找回来；③ 资源中心的「下载 / 安装到实例」按钮不再被挤成 0 高度。
2.3.3 的改动：整合包识别更准，zip 里面再套一层 mrpack 也能认出来。

Linux 版

Linux 源码包 2.3.5（2.3 MB） 主镜像 备镜像 任意发行版

是源码包，不是编译好的二进制：启动器本身是纯 Python + tkinter，同一份代码在 Linux 上跑，不用为每个发行版编译一遍。
解压后 sh linux/launcher.sh 开界面（需要 python3 和 python3-tk：sudo apt install python3-tk）；没桌面环境就用 sh linux/launcher.sh --web 8765 开网页控制台。想进应用菜单：sh linux/install.sh，卸载 sh linux/install.sh --uninstall，不动存档和模组。
包里带 README-Linux.txt，发行版差异、Termux、Java 都写在里面。

安卓版

安卓版（155 MB） Android 5.0 以上
主镜像 · 安卓版 备镜像 · 安卓版

账号和电脑版互通：在电脑上注册「启动器账号」，手机填电脑上显示的那个地址，用的就是同一个号。另外两种是正版账号（微软）和离线账号。
联机不用租服务器：电脑版「服务端」页点一下开服，同一个 Wi-Fi 把地址发给朋友就能进；不在一个 Wi-Fi，两边都有 IPv6 也能连。

系统要求

  • Windows 10（1809 以上）或 11，32 / 64 位
  • Linux：任意发行版 + python3 + python3-tk（没有桌面就用网页控制台）
  • 安卓 5.0 以上
  • 内存 4 GB 以上，加模组建议 8 GB

第一次打开 Windows 可能弹「已保护你的电脑」，点「更多信息 → 仍要运行」。没买商业证书，都会这样。
下完双击，第一次选游戏目录，选版本点启动。

常见问题

要自己装 Java 吗？不用，它按你选的游戏版本自己准备。

怎么卸载？「设置 → 应用」里卸载，或者开始菜单右键。只删程序本身，存档和模组不动；便携版删掉 exe 就行。
