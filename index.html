账号和电脑版互通：在电脑上注册「启动器账号」，手机填电脑上显示的那个地址，用的就是同一个号。另外两种是正版账号（微软）和离线账号。
联机不用租服务器：电脑版「服务端」页点一下开服，同一个 Wi-Fi 把地址发给朋友就能进；不在一个 Wi-Fi，两边都有 IPv6 也能连。

系统要求

  • Windows 10（1809 以上）或 11，32 / 64 位
  • 安卓 5.0 以上
  • 内存 4 GB 以上，加模组建议 8 GB

第一次打开 Windows 可能弹「已保护你的电脑」，点「更多信息 → 仍要运行」。没买商业证书，都会这样。
下完双击，第一次选游戏目录，选版本点启动。

常见问题

要自己装 Java 吗？不用，它按你选的游戏版本自己准备。

怎么卸载？「设置 → 应用」里卸载，或者开始菜单右键。只删程序本身，存档和模组不动；便携版删掉 exe 就行。
