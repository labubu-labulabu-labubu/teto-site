07

常见问题

要自己装 Java 吗？

不用。它按你选的游戏版本自己准备对应的 Java，装在启动器自己的目录里，不碰系统环境变量。

怎么卸载？

安装版：「设置 → 应用」里卸载，或者开始菜单右键。只删程序本身，存档和模组不动。便携版删掉 exe 就行。

存档会丢吗？

不会。存档、模组、配置都在游戏目录里，卸载和升级都不动它们。换机器把整个游戏目录拷走即可。

和朋友联机要开端口吗？

同一个 Wi-Fi 不用。不在一个网络时，两边都有 IPv6 也能直连；都没有就内置的陶瓦联机走中转。
