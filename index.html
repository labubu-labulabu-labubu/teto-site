能做什么

  • 选版本、下载游戏文件、启动，全程在界面里点，不用手动改配置文件。
  • 装模组：Fabric、Forge、NeoForge、Quilt；整合包（.mrpack / .zip）可以直接导入。

常见问题

要自己装 Java 吗？

不用。启动器会按你选的游戏版本准备对应的 Java 运行时，只准备游戏要用的那个。

它会不会往系统里乱装东西？

不会。游戏和模组都放在你自己指定的目录里，安装包只写自己的程序目录，卸载时一起清掉。

怎么卸载？

Windows 设置 → 应用 → 已安装的应用 → 找到「海豚启动器」→ 卸载。游戏目录不会跟着删，需要的话自己删。

支持哪些版本？

1.7.10 及以上，原版和主流的模组加载器都可以。

为什么没有代码签名？

个人项目，没有买证书。所以会出现 SmartScreen 提示，这是没签名程序的正常表现，不代表文件有问题。

系统要求

  • Windows 10（1809 及以上）或 Windows 11，64 位
  • 内存 4 GB 以上；加模组建议 8 GB
  • 程序本身约 300 MB，游戏文件和模组另算
