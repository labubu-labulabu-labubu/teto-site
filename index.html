怎么用

  1. 下安装版双击装。不想装就用便携版，双击直接开。
  2. 第一次打开让你选游戏目录，默认是桌面的 .minecraft，想换就点「浏览」。
  3. 左边选版本，没装的点「安装」，然后点「启动游戏」。

第一次打开 Windows 可能弹「已保护你的电脑」，点「更多信息 → 仍要运行」。签名是自签的，没买商业证书，系统默认不认。

1.7.10 到现在的版本都能玩，原版和主流的模组加载器都行：Fabric、Forge、NeoForge、Quilt、OptiFine。以前装好的版本能原地导进来，不用重下。没正版账号也能玩单人，要连正版服务器再登微软账号。

常见问题

要自己装 Java 吗？

不用。启动器按你选的游戏版本自己准备 Java，你什么都不用配。

会不会往系统里乱装东西？

安装版只在当前用户下写一条卸载记录，不装服务、不动系统目录。配置和日志在 %LOCALAPPDATA%\DolphinCraftLauncher，游戏和模组都在你自己指定的目录里。

怎么卸载？

「设置 → 应用 → 已安装的应用」里找到它点卸载，开始菜单右键也有。只删程序本身，存档、模组、游戏本体都不动。便携版把 exe 删掉就行。

为什么说它不安全？

签名是自签的，没买商业代码签名证书，Windows 默认不信任这个签名者，SmartScreen 就会拦一下。文件有没有被改过，比上面的校验值。
